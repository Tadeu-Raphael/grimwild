# 1.1.0

## New features

- Added Treasures as an item type and character sheet tab, replacing the Arcana tab.
- Treasures can have a Minor, Major, or Mythic value and be Tangible, Intangible, or Magic.
- Magic treasures can be marked as Arcana to expose touchstones, limitations, and trackers.
- Migrated the 62 Arcana compendium entries to Magic Arcana treasures.

## Compatibility

- Existing Arcana items remain supported.
